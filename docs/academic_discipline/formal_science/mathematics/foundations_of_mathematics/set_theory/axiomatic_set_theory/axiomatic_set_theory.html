公理的集合論

目次[表示]

概要

 19世紀末から20世紀初頭にかけて、数学は急速に抽象化と形式化の道を進み始めた。その中で、「集合」という概念があらゆる数学的対象を統一的に扱う基盤として登場する。しかし、素朴集合論（naive set theory）の段階では、「性質で定まるもの全体の集まり」を自由に考えてよいとされていたため、ラッセルのパラドックス[1]をはじめとする自己言及的な矛盾が露呈した。

 この危機に対処するため、集合の構成を厳密に制限し、矛盾の生じないようにした体系的な理論が「公理的集合論」である。ここでは、「集合とは何か」を定義するのではなく、「集合がどのようにふるまうか」を公理の集合として定める。つまり、集合論は対象を直接説明するのではなく、集合に関する論理的な法則を定めることによって数学の基礎を築く。

 今日の数学のほとんどは、ツェルメロ＝フレンケル集合論（以降ZF）または選択公理を加えたZFCを前提として記述されている。これにより、「数」「関数」「空間」「順序」などあらゆる概念を集合の上に構築することが可能になった。一方で、ZFCはあくまで数学の「標準的」基礎であり、それ自体にも限界や拡張の余地がある。たとえば、クラスを明示的に扱う理論や、圏論的な基礎づけなどが、その後の展開として現れている。

公理化の意義とその展開

 公理的集合論の目的は、単に矛盾を避けることではない。どちらかと言うと、数学のあらゆる対象を一つの統一的な言語で扱うことにある。

 たとえば、自然数、実数、写像、ベクトル空間、位相空間などは、すべて集合として構成される[2]。これにより、数学の定理を「集合と論理」に還元して考えることができるようになった。

 しかし同時に、ゲーデルの不完全性定理やコーエンの強制法（forcing）によって、集合論の公理体系自体にも「決定できない命題」が存在することが明らかになった。たとえば、連続体仮説の真偽はZFCでは決められない。この発見は、数学の基礎が絶対的ではなく、選択された公理系に依存することを示している。

 このように公理的集合論は、単なる技術的基盤にとどまらず、数学そのものの限界と構造を探る理論的探求でもある。

 公理的集合論にはいくつかの主要な体系が存在し、それぞれが素朴集合論の矛盾を回避しつつ、数学の基礎を異なる形で提供している。以下に、主な体系を挙げる。

 フォン・ノイマン＝ベルナイス＝ゲーデル集合論（NBG）は、ZFを拡張し、「集合」と「クラス」を区別して扱う理論。ZFとほぼ同程度の表現力を持ちながら、メタ的議論を内部で行えるという利点がある。NBGでは、全ての集合を含む「全クラス」が定義可能であるため、集合論そのものを理論内部で記述しやすい。

 モース＝ケリー集合論（MK）は、NBGをさらに拡張し、クラスに関する内包公理[3]（Comprehension Axiom）をより自由に認めた理論。NBGよりも強力で、特に大きな階層構造を扱う研究（大きな基数やクラス階層など）に適している。
