テキスト検索

  • 単純文字列検索（Substring Search）

      正規表現検索について

      まず重要な点として、/.../ 形式で入力しない限り正規表現検索にはならない。 例: /foo.*bar/i は正規表現検索になるが、foo.*bar は通常の文字列検索になる。

      正規表現は /pattern/flags の形式で入力すると有効になる。 利用可能なフラグは g, i, m, u, y。

      検索対象は label、labelEn、各セクションの見出し（h2）および本文。 JavaScript の RegExp.test() により一致判定を行う。

      構文が誤っている正規表現は無効として扱う。 その場合、検索は実行されずエラー通知が表示される。

      注意点
      ・論理演算子検索（AND/OR/NOT）とは組み合わせられない
      ・g フラグ使用時は lastIndex により一致判定が変化する可能性がある
      ・/.../ 形式以外は常に通常検索として処理される

      検索候補
      ・入力した文字列が既存のページ名に含まれるものであった場合、入力欄下部に検索候補が表示されます。ただし、候補は10項目までしか表示されません。
      ・検索候補内のタイトルを押下すると、その文字列を入力欄に追加できます。
      ・検索候補内のアイコン「」を押下すると直接リンク先のページを開くことができます。
