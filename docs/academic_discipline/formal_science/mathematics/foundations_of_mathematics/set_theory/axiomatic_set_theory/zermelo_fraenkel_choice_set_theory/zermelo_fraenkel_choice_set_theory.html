概要

 公理的集合論の中でも最も広く用いられているのが ZFC集合論（Zermelo-Fraenkel Set Theory with the Axiom of Choice）です。本稿では、ZFC集合論の構成、公理系、直観、限界などについてまとめる。また、以降に出てくる記号$\in$、$\notin$は、集合論にて扱っているため、既知とする。

ZFC集合論の構成

 ZFC集合論は以下の3つの特徴を持つ：

  1. Zermelo-Fraenkel（ZF）：基本的な集合の操作を制御するための公理群。
  2. Choice（C）：選択公理。任意の集合族から1つずつ選ぶことができるという強力な仮定。
  3. 一階述語論理：論理的な推論は一階論理で行い、集合のみを変数の対象とする。
ZFCは、現在の数学の大部分が依拠する形式的基盤であり、算術・実解析・代数・位相などあらゆる分野の理論構築に使用されている。

ZFC集合論の公理系
 ZFCは以下のような9つの（公理スキームを含む）基本公理から成り立ちます。各公理は集合がどのように構成されるか、どのように振る舞うかを制御します。

  1. 外延性公理（Extensionality）
  2. 空集合の公理（Empty set）
  3. 分出公理スキーム（Separation schema）
  4. 対の公理（Pairing）
  5. 和集合の公理（Union）
  6. 冪集合の公理（Power set）
  7. 無限公理（Infinity）
  8. 置換公理スキーム（Replacement schema）
  9. 正則性（基礎の）公理（Regularity / Foundation）
  10. 選択公理（Axiom of Choice）
