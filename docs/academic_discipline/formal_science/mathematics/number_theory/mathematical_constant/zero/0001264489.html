近似値と円周率の誤差

目次

概要

 円周率の計算式は数あれど、近似値としてよく知られる値と円周率の差が斯くも興味深い式で表せるとは。特に右辺の対称性がおもしろい。

\[ \frac{22}{7} - \pi = \int_{0}^{1} \frac{x^{4}(1 - x)^{4}}{1 + x^{2}} dx \]
0001264489.ipynb
import numpy as np
import scipy

# 円周率と近似値の誤差
result, err = scipy.integrate.quad(lambda x: ((x ** 4) * (1 - x) ** 4) / (1 + x ** 2), 0, 1)
print(f"積分 {result}")
print(f"22 / 7 - π {22 / 7 - np.pi}")
