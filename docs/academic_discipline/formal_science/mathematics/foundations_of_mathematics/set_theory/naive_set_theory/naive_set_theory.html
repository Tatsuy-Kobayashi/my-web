素朴集合論の背景と意義

 まるで「集合論の基礎」、「基礎的な集合論」であるかのような顔で鎮座しているが、もちろん「素朴」という修飾語がある時点で歴史上初めの集合論というわけではない。おそらくそのような集合論にあたるのは、高校で勉強するような集合論だろう。集合論は、数学のあらゆる分野の基礎をなす概念──すなわち「ものの集まり」を形式的に扱う学問領域だ。19世紀後半から20世紀初頭にかけ、フレーゲやラッセルらによって展開された集合論は、直感に近い「すべての性質に対応して集合が取れる」という素朴な理解（素朴包括原理）が採用されていた。しかし、この素朴素朴包括原理は、後にラッセルのパラドックスなどのいくつかの矛盾を引き起こすことが判明した。そこでいくつかの集合論がそれら矛盾を排除する形で発展させてきたが、排除してしまってはそのような命題を取り扱うことすらできない。そこで、旧ソビエト連邦の論理学者ヴラジーミル・ニコラエヴィチ・グリシン (Vladimir Nikolaevich Grishin) は、数学者や論理学者が直感的に捉える「集合」という概念自体の魅力と有効性を強調し、可能な限りその直感を反映した体系づくりを試みた。

 ところで、全くの基礎分野ではないと言ったものの、それはあくまで理念であって、集合の基礎的な部分も扱うので安心してほしい。
