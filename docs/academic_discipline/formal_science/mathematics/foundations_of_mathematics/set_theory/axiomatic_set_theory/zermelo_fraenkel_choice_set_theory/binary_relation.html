     一般的な二項演算 $+, \times$ からより高次の二項演算を「繰り返し」の取り方から導入できる。つまり、和 $+$ を繰り返すことで積 $\times$ を定義できる。

    \[ a \times b = \underbrace{a+a+\dots +a}_{\text{長さ }b}. \]

    このことから積を

    \[ a^{b} = \underbrace{a \times a \times \dots \times a}_{\text{長さ }b}. \]

    として冪乗を定義できることがわかる。

     ここで今、$\mathrm{hyper}(a, 1, b) = a + b$、$\mathrm{hyper}(a, 2, b) = a \times b$ とすれば、各演算は漸化式

    \[ \mathrm{hyper}(a, n, b) = \mathrm{hyper}(a, n-1, \mathrm{hyper}(a, n, b - 1)). \]

    で表せる。実際、$n = 2$ のとき、

    \[ a \times b = \mathrm{hyper}(a, 2-1, a \times (b - 1)). \]

    ここで、$\mathrm{hyper}(a, 1, b) = a + b$ より、

    \[ \begin{align*} a \times b &= \mathrm{hyper}(a, 1, a \times (b - 1)) \\ &= a + a(b-1) \\ &= a + ab - a \\ &= ab. \end{align*} \]

    となり、満たしている。一方、$n = 1$ から $n = 0$ を定義できるだろうか？

    \[ \begin{align*} \mathrm{hyper}(a, 1, b) &= \mathrm{hyper}(a, 0, \mathrm{hyper}(a, 1, b - 1)) \\ a + b &= \mathrm{hyper}(a, 0, a + (b - 1)) \\ &= \mathrm{hyper}(a, 0, a + b - 1). \end{align*} \]

    ここで、$c = a + b - 1$ と置くと、

    \[ \begin{align*} a + b &= \mathrm{hyper}(a, 0, a + b - 1) \\ c + 1 &= \mathrm{hyper}(a, 0, c) \end{align*} \]

    となり、これが $n = 0$ の定義である。ここまでのことから、二項演算の一般化を

    \[ \mathrm{hyper}(a, n, b) = \begin{cases} b + 1 & \text{if } n = 0 \\ a & \text{if } n = 1, b = 0 \\ 0 & \text{if } n = 2, b = 0 \\ 1 & \text{if } n \geq 3, b = 0 \\ \mathrm{hyper}(a, n-1, \mathrm{hyper}(a, n, b - 1)) & \text{otherwise} \end{cases} \]

    と再帰的に定義できる。ただし、この記法は二項演算というよりは、関数的なので厳密な用語の扱いには注意が必要である。しかし、自由度は関数の方が高いので、二項演算を関数化するのに問題はない。
