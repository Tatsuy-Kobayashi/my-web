概要

 さまざまな集合論に対して共通の概念を定義する。もちろんこれらはそれぞれの集合論の公理から演繹的に導かれるものであるが、「集合論の基礎」として重要な部分をまとめておくのも良いだろう。ここで述べることの多くは、離散的で有限な数学的対象に関するものである。

集合の基本概念と用語

集合
 集合は「ある条件に基づいて選ばれた対象のまとまり」を意味する。たとえば、「自然数全体の集合」や「赤い果物の集合」などがその典型としてあげられる。また、集合を構成する個々の対象を元（要素）と呼ぶ。

帰属関係
 $x$ が集合 $A$ の要素である場合、 x は A に属している、または x は A に含まれると表現する（ただし、包含関係という場合は部分集合を表す）。これは

\[ a \in A \]

で表される。記号 $\in$ は、1889年にジュゼッペ・ペアノによって導入された、ギリシャ文字の小文字のイプシロン「ε」から派生したもので、ἐστί（「is」の意味）という単語の最初の文字である。記号 $\notin$ は、$x \notin A$ という表記でよく用いられ「x は A に含まれない」という意味になる。

 集合の集合(要素が集合である集合)を、特に集合族という。

 元が$1$つである集合を、特に一（いち）元集合という。また、元が存在しない集合を空集合といい、記号$\varnothing$（$\emptyset$）または$\{\}$（$(\ |\ )$）で表す。集合はその要素によって完全に定まるため、空集合は1種類だけである（空集合の公理を参照）。空集合には要素がないが、他の集合（集合族）の要素である可能性はある。したがって、前者には要素がなく、後者には1つの要素があるため、$\varnothing \neq \{ \varnothing \}$ である。

ex1)

 元が$x$のみである集合$\{ x\}$は一元集合であり、$x$とは異なる数学的対象として考える。

ex2)

 $1$桁の自然数の集合は、外延的表記によって、

\[ S = \{1, 2, 3, 4, 5, 6, 7, 8, 9\} \]

と表される。また集合の定義は、

\[ S = \{x \mid 1 \leq x \leq 9, x \in \mathbb{N}\} \]

のように条件を示す方法（内包的表記）でも行われる。

ex3)

 元が$x$のみである集合$\{ x\}$は一元集合であり、$x$とは異なる数学的対象として考える。

ex4)

  •  素数全体の集合を$\mathbb{P}$とする。
  • $2$は素数であるから、$2$は集合$P$に属する。ゆえに、$2\in P$が成り立つ。
  • $6$は素数でないから、$6$は集合$P$に属さない。ゆえに、$6\not\in P$が成り立つ。

    •  Pythonには、「集合」というデータ型が用意されている。

                通常、数学の集合には、要素に順番はなく要素に重複もない。Pythonの集合型にも要素の順番はなく要素に重複もない。ソースコード例にもあるように集合族も定義できないことはないが、単にまとまりを元としたいだけなら、タプルを元とした方が良い（例：冪（べき）集合、直積集合）。
            
    
            
    
                部分集合
    
                 任意の集合$A$の元が集合$B$の元であるとき、$A$は$B$に含まれる、$B$は$A$を含むといい、$A\subseteq B$、$B\supseteq A$と書く。また、$A$を$B$の部分集合という。$A\subseteq B$かつ$B\subseteq A$であるとき、$A$と$B$は等しいといい、$A=B$と書く。また、$A=B$が成り立たないとき、$A\neq B$と書く。$B$と等しくない$B$の部分集合を真部分集合といい、$A\subset B$と書く（文章によっては、$A$と$B$が等しい場合も含む部分集合を$A\subset B$と書き、真部分集合を$A\subsetneq B$と書くこともある。しかしその場合、否定を含意しない記号$\subseteq$は活用しないのか？という当然の疑問がうまれる）。
            
    
            
    
                 全ての集合は空集合を部分集合として含む：任意の集合 $A$ に対し、$\varnothing \subseteq A$である。何故なら、任意の集合 $A$ に対し、命題「${}^{\forall} x : x \in \varnothing \Rightarrow x \in A$」は常に真だからである（空虚な真参照。なぜ前件が真にならないのかと言うと、空集合には要素がないからである）。特に$A = \varnothing$とすれば、$\varnothing \subseteq \varnothing$が成り立つことも分かる。また、空集合の部分集合は空集合自身のみである。
            
    
            
    
                冪（べき）集合
    
                 任意の集合$A$に対し、$A$の部分集合全体の集合を$A$の冪集合といい、$\mathcal{P}(A)$、$\mathfrak{P}(A)$、$P(A)$、${2}^{A}$などと書く。冪集合は集合族の一つである。冪集合の要素数は$2^{|A|}$となる。
            
    
            
    
                集合の大きさ（濃度、基数）
    
                 集合$A$の元の個数を$|A|$と記し、その値が有限であるものを有限集合、有限でないものを無限集合という。無限集合の場合は、集合の濃度を考えないとき$|A|=\infty$と表現することもある。また、基数は$\#A$や$\operatorname{Card}(A)$と表現することもある。
            
    
            
    
                 なお、数学では自然数全体の集合を$\mathbb{N}$、整数全体の集合を$\mathbb{Z}$、有理数全体の集合を$\mathbb{Q}$、実数全体の集合を$\mathbb{R}$、複素数全体の集合を$\mathbb{C}$と書く。ただし、自然数の定義は文脈によって異なるので注意すること。また、素数全体の集合を記号$\mathbb{P}$とする場合がある。
            
    
            
    
                
    
                    
    ex5)
    
                    
    
                        
     集合$A = \{ 1, 2, 5 \}$のすべての元は自然数であるから、$A$は自然数の部分集合であり、$A\subseteq \mathbb{N}$と書ける。
    
                    
    
                    
    ex6)
    
                    
    
                        
     集合$A = \{ 1, 2, 5 \}$の冪集合は
                            
    
                                
    
                                    \[
                                        \mathcal{P}(A) = \{ \varnothing, \{ 1 \}, \{ 2 \}, \{ 5 \}, \{ 1, 2 \}, \{ 1, 5 \}, \{ 2, 5 \}, \{ 1, 2, 5 \}  \}
                                    \]
                                
    
                            
    
                            である。
                        
    
                    
    
                    
    ex7)
    
                    
    
                        
     集合$A = \{ 1, 2, 5 \}$の要素数は$|A|=3$である。
    
                    
    
                    
    ex7)
    
                    
    
                        
    
                             無限集合の大きさは濃度（可算濃度、連続体濃度）で表す。
    
                            
    
                                
    
                                    \[
                                        \# \mathbb{N} = \aleph_{0} = \beth_{0}, \ \# \mathbb{R} =\aleph = \mathfrak{c}
                                    \]
                                
    
                            
    
                        
    
                    
    
                    
    命題1: 
    
                    
    
                        
     冪集合の要素数は$2^{|A|}$となる。
    
                        
    
                            証明
    
                             $|A| = n$と置く。冪集合の定義より、冪集合の各元は、要素数$0$の集合、要素数$1$の集合、要素数$2$の集合、、、要素数$n$の集合の各組合せであり、それらの集合の構成パターンは、それぞれ${}_n \mathrm{C}_{0}$、${}_n \mathrm{C}_{1}$、${}_n \mathrm{C}_{2}$、、、${}_n \mathrm{C}_{n}$となる。ここで二項定理より、
                        
    
                        
    
                            
    
                                \[
                                    \sum_{i=0}^{n} {}_n \mathrm{C}_{i} = 2^{n} = 2^{|A|}.
                                \]
                            
    
                        
    
                        
    よって示された。

                集合の代数学
    
                 数の基礎──群論などでは、各数体の演算について学ぶが、集合にも演算がある。以下の演算によって、集合の直感的かつ基本的な操作が可能になる。
            
    
            
    
                
  • 和集合（Union）
    • 
                 2つの集合$A, B$の和集合を
            
    
            
    
                
    
                    \[
                        A \cup B = \{ x \mid x \in A \lor x \in B \}
                    \]
                
    
            
    
            
    と定義する。
    
            
    
                
    
                    
    
                        
    
                            
                        
    
                    
    
                    
                
    
            
    
            
    
                 和集合には交換法則と結合法則が成り立つ。
            
    
            
    
                
    
                    \begin{equation*}
                        \begin{aligned}
                            A \cup B &= B \cup A \\
                            A \cup (B \cup C) &= (A \cup B) \cup C
                        \end{aligned}
                    \end{equation*}
                
    
            
    
            
    
                
  • 積集合（Intersection、共通部分、交叉）
    • 
                 2つの集合$A, B$の共通部分を
            
    
            
    
                
    
                    \[
                        A \cap B = \{ x \mid x \in A \land x \in B \}
                    \]
                
    
            
    
            
    と定義する。
    
            
    
                
    
                    
    
                        
    
                            
                        
    
                    
    
                    
                
    
            
    
            
    
                 積集合には交換法則と結合法則が成り立つ。
            
    
            
    
                
    
                    \begin{equation*}
                        \begin{aligned}
                            A \cap B &= B \cap A \\
                            A \cap (B \cap C) &= (A \cap B) \cap C
                        \end{aligned}
                    \end{equation*}
                
    
            
    
            
    
                 集合$A, B, C$に対し，次の分配法則（分配律）が成り立つ。
            
    
            
    
                
    
                    \begin{equation*}
                        \begin{aligned}
                            A \cup (B \cap C) &= (A \cup B) \cap (A \cup C) \\
                            A \cap (B \cup C) &= (A \cap B) \cup (A \cap C)
                        \end{aligned}
                    \end{equation*}
                
    
            
    
            
    
                
  • 差集合（Difference、相対補集合）
    • 
                 2つの集合$A, B$の差集合を
            
    
            
    
                
    
                    \[
                        A - B = A \setminus B = \{ x \mid x \in A \text{ and not } x \in B \} = \{ x \in A \mid \neg \, x \in B \}
                    \]
                
    
            
    
            
    と定義する。
    
            
    
                
    
                    
    
                        
    
                            
                        
    
                    
    
                    
                
    
            
    
            
    
                
  • （絶対）補集合（complement）
    • 
                 特定の状況では、考えているすべての集合を、特定の普遍集合（Universal set）の部分集合と見なすことができる。真の普遍集合は標準集合論には含まれていないが、一部の非標準集合論には含まれている。
            
    
            
    
                 普遍集合$U$と$U$の部分集合$X$が与えられたとき、$X$の補集合（$U$の部分集合）を
            
    
            
    
                
    
                    \[
                        X^{C} =U \setminus X = \{ x \mid x \in U \text{ and not } x \in X \} = \{ x \in U \mid \neg \, x \in X \}
                    \]
                
    
            
    
            
    と定義する。言い換えると、$X^{C}$（"A-complement"）は、$A$ の要素ではない $U$ のすべての要素の集合である。
    
            
    
                
  • 対称差（Symmetric difference）
    • 
                 2つの集合$A, B$の対称差を
            
    
            
    
                
    
                    \[
                        A \ominus B = A \bigtriangleup B = \{ x \mid x \in A \veebar x \in B \}
                    \]
                
    
            
    
            
    と定義する。
    
            
    
                
    
                    
    
                        
    
                            
                        
    
                    
    
                    
                
    
            
    
            
    
                 対称差には交換法則と結合法則が成り立つ。
            
    
            
    
                
    
                    \begin{equation*}
                        \begin{aligned}
                            A \bigtriangleup B &= B \bigtriangleup A \\
                            A \bigtriangleup (B \bigtriangleup C) &= (A \bigtriangleup B) \bigtriangleup C
                        \end{aligned}
                    \end{equation*}
                
    
            
    
            
    
                
  • 直積 [デカルト積]（Direct product [Cartesian product]）
    • 
                 解析幾何学で周知のように、Descartes（デカルト）座標を用いれば、平面上の一点は二つの実数 $x,y$ の対 $(x,y)$ として表わされる。二点 $(x,y)$, $(x', y')$ が一致するために必要にして十分な条件は $x = x', y = y'$ である。このような数の組を順序対（ordered pair）と呼ぶ。
            
    
            
    
                 ここで上記の順序対を用いて2つの集合$A, B$の直積を
            
    
            
    
                
    
                    \[
                        A \times B = \{ (x, y) \mid x \in A \land y \in B \}
                    \]
                
    
            
    
            
    
                と定義できる。直積のZFC公理系からの導出は、ツェルメロ＝フレンケル集合論の命題 7.1を参照されたい。
            
    
            
    
                 再び解析幾何学の観点で述べると、$x$ を $A \times B$ の元 $(x,y) = z$ の 'A座標' または 'Aへの射影' (projection onto A) といい $\mathrm{pr}_{A}(z)$ で表せる。同様に $y$ を $(x,y) = z$ の 'B座標' または 'Bへの射影' といい $\mathrm{pr}_{B}(z)$ で表せる。
            
    
            
    
                
    集合の代数学
    
                
    
                    
    
                
     
                
    
                    
    ->
    
                    
    {1, 2, 3} と {3, 4, 5} の和集合: {1, 2, 3, 4, 5}
{1, 2, 3} と {3, 4, 5} の積集合: {3}
{1, 2, 3} と {3, 4, 5} の差集合: {1, 2}
{1, 2, 3} と {3, 4, 5} の対称差: {1, 2, 4, 5}
全体集合 {1, 2, 3, 4, 5, 6} に対する set1 {1, 2, 3} の補集合: {4, 5, 6}
{1, 2} と {'b', 'a'} の直積集合: {(2, 'a'), (2, 'b'), (1, 'a'), (1, 'b')}
    
                
    
            
     
            
    
                ベン図
    
                 集合論において、必須の概念というわけではないが、2、3の集合の関係（特に交叉）を分かりやすくする道具を紹介しておく（複数とは言わないのは、4つを超える集合の場合には、必ずしも見やすくなるわけではないからである）。
