HTML・CSS・JavaScriptエディタ

目次

概要

 この世で最も楽に実装できるプログラミング言語は JavaScript だろう。特に開発側ではなく、通常の PC を普段使いしている一般ユーザにとっては、非常に簡易なものである。しかし、完全に手間が無いというわけではない。まず、ファイルを作成して保存しなければならないが、ファイルの書きやすさは使っているエディタに依存する。また、ファイルを保存するためには、少なからずディレクトリ構造を意識しなければならない。さらにブラウザ上で実行するためには少なくとも HTML ファイルが必要で、開発環境（ソースコードを書くところ）と実行環境が別なのも地味に面倒くさい。そういった手間を解決したいと思いこのページを作った。

 ちなみに実行に HTML ファイルが必要なら、最も楽に実装できるプログラミング言語は HTML じゃあないのか？と思う人もいるかもしれない 。しかし、HTML はデータ記述言語であってプログラミング言語ではない。

HTML 
<div id="test-area">
    <h1>使用例</h1>
    <button id="toggle-button">クリックして色を変える</button>
    <div>
        <input type="text" id="inputForm" value="Hello, world!">
        <button id="input-button">入力内容を表示</button>
    </div>
    <div id="outputter">入力内容：<span id="outputting"></span></div>
</div>
CSS 
#test-area {
    text-align: center;
    margin-top: 20px;
}

#toggle-button {
    padding: 10px 20px;
    background-color: lightcoral;
    color: white;
    border: none;
    cursor: pointer;
}

#toggle-button:hover {
    background-color: coral;
}
JavaScript 
// トグル切り替えの処理
document.getElementById('test-button').addEventListener('click', () => {
    const testArea = document.getElementById('test-area');
    const currentColor = testArea.style.backgroundColor;

    // 背景色を lightblue と white の間で切り替え
    if (currentColor === 'lightblue') {
        testArea.style.backgroundColor = 'white';
    } else {
        testArea.style.backgroundColor = 'lightblue';
    }
    console.log('ボタンがクリックされ、背景色が変わりました！');
    alert('ボタンがクリックされ、背景色が変わりました！');
});
// 入力内容を表示する処理
document.getElementById('input-button').addEventListener('click', updateSentence);
function updateSentence() {
    const inputSentence = document.getElementById('inputForm').value;
    const outputDisplay = document.getElementById('outputting');
    outputDisplay.innerText = inputSentence;
}
