特殊関数

 初等関数の代数的操作や合成では定義できないような関数を特殊関数と呼ぶ。初等関数の微分は初等関数になるが、初等関数の積分は必ずしも初等関数になるとは限らない。上記を満たしていても、一般的に超関数は、特殊関数には含まない。

絶対値　区分（定義）関数piecewise(-defined) function

 絶対値を含む関数は、特殊関数となる場合がある。分岐的に定義される piecewise 関数。非連続微分点を持つため解析的とは限らないが、広義には初等的。

床関数と天井関数

 床関数（floor function）と天井関数（ceiling function）は、整数に丸める関数である。床関数は、与えられた実数以下の最大の整数を返し、天井関数は、与えられた実数以上の最小の整数を返す。これらも特殊関数の一種である。数論や計算機科学では重要。微分不可能な点が多く、通常の解析関数ではない。
