解説

            
1. 導入

            

                 これは、群の位数 $p^{n}$ の同型類の数を列挙する関数 $f(n,p)$ および制限された種類の $p$-群を列挙する関数について議論する、3本の論文の最初のものである。本論文では主に、タイトルが示す通り、$f(n,p)$ に対する不等式に焦点を当てている。我々の結果として、
            

            \[
                f(n,p) = p^{An^{3}},
            \]
            

                と定義するとき（ここで、$A$ は $n$ と $p$ に依存する）、次の不等式が成り立つ：
            

            \[
                \frac{2}{27} - \epsilon_{n} \leq A \leq \frac{2}{15} + \epsilon_{n}, (1.1)
            \]
            

                ただし、本論文を通じて、$\epsilon_{n}$ は $n$ のみに依存し、$n \to \infty$ とするとゼロに収束する数である。また、付随的に生じ、独立して興味深いと思われる問題として、次のことがある。$GL_{n}(p)$（$p$ 個の元を持つ体上の次元 $n$ の完全線型群）の Sylow $p$ 部分群における共役類の数が $p^{Bn^{2}}$ であるとすると、次の不等式が成り立つことを示す：
            

            \[
                \frac{1}{12} - \epsilon_{n} \leq B \leq \frac{1}{4} + \epsilon_{n}. (1.2)
            \]
            

                ここで、その上限を改善することができれば、(1.1) の上限も改善できるが、両不等式のギャップを完全に埋めることはできない。
            

            

                 シリーズの他の論文では、固定した $n$ に対して $f(n, p)$ がどのような $p$ の関数であるかという、より興味深いかもしれない問題について議論する予定である。もちろん、関数 $f(n,p)$ は $n \leq 5$ の場合には既に知られている（$n \leq 4$ については Burnside[2]、$n = 5$ については Schreier[3]の研究を参照）。これらの場合の結果は、与えられた $n$ に対して整数 $N$ が存在し、$p$ が'$N$ を法とする固定された剰余類'を取ると $f(n, p)$ が多項式であることを示唆している。このことを証明することはできないが、第2論文において、$\Phi$-類が高々 $2$ である $p$-群（つまり、中心基本アーベル部分群を持ち、その商群も基本アーベルである $p$-群）を列挙する関数について対応する結果を証明する。この結果は、$q$ 個の元を持つ体 $F_{q}$ に関する列挙問題についての、一般的な定理の特殊な場合として現れる。この定理はまた、例えば、$F_{q}$ 上の与えられた次数、与えられた変数の数における非同値な形式の数を列挙する問題にも適用される。
            


            
2. 下限

            

                 $f(n,p)$ の下限は $\Phi$-類が 2 の $p$-群を考えることで得られる。このような群は中心基本アーベルな $\Phi$ 部分群を持ち、$\Phi$ 部分群の指数が $p^{r}$、位数が $p^{s}$ であるとき、その群を $\Phi$-組成 $(r, s)$ を持つものと記述する。$\Phi$-組成 $(r, s)$ を持つ $p$-群の同型類の数を $g(r, s; p)$、また、位数 $p^{n}$ の $\Phi$-類が 2 の $p$-群の同型類の数を $f_2(n,p)$ と表す。
            

            

                 定理 2.1. $s \gt \frac{1}{2} r (r + 1)$ ならば $g(r, s; p) = 0$ だが、$s \leq \frac{1}{2} r (r + 1)$ ならば不等式
            

            \[
                p^{\frac{1}{2} r s (r + 1) -r^{2} - s^{2}} \leq g(r,s;p) \leq p^{\frac{1}{2} r s (r + 1) - s (s - 1)}
            \]
            

                が成り立つ。
            

            

                 $G$ が $\Phi$ 部分群の指数が $p^{r}$ である $p$-群であれば、$G$ は $r$ 個の元で生成される。そこで、$\Phi$ 部分群が中心基本アーベルな $r$ 個の元で生成される最大の $p$-群を構成することから始める。$a_{1}$, $a_{2}$, ..., $a_{r}$ を自由生成元とする自由群 $F$ を取り、$F$ 内の $x^{p^{2}}$, $(x, y)^{p}$, $(x^{p}, y)$, および $((x, y), z)$ が生成する完全不変部分群 $R$ を考える。$F/R = H$ とすると、$H$ は $r$ 個の元 $h_{i} = a_{i}R$ ($i = 1, ..., r$) で生成される $p$-群となり、$\Phi(H)$ は交換子 $(x, y)$ および $x^{p}$ によって生成されるため、定義により $R$ が中心基本アーベルである。逆に、$G$が$p$-群で、生成元が$g_{1}, g_{2}, \ldots, g_{r}$であり、$\Phi(G)$が中心基本アーベルであるとします。このとき、$G$内では$x^{p^{2}} = (x, y)^{p} = (x^{p}, y) = ((x, y), z) = 1$という同値関係が成立します。したがって、$F$から$G$への準同型写像において、$a_{i}$が$g_{i}$に写るとすると、その核には$R$が含まれる。よって、$G$は$H$の準同型の像であり、$G \simeq H/N$と表すことができます。また、生成元$g_{1}, \ldots, g_{r}$が冗長でない場合、$N$は$\Phi(H)$に含まれる。
            

            

                 次に、$H$ は $h_{1}, h_{2}, \ldots, h_{r}$ によって生成されるため、$\Phi(H)$ は $h_{1}^{p}, h_{2}^{p}, \ldots, h_{r}^{p}$ と交換子群によって生成される。しかし、交換子群は交換子 $(h_{i}, h_{j})$（$1 \leq i \lt j \leq r$）およびその共役によって生成されるが、これは中心的なため、交換子自体によって生成されることになる。したがって、$\Phi(H)$ は次の $\frac{1}{2} r (r + 1)$ 個の要素によって生成される：
            

            \[
                h_{i}^{p}, 1 \leq i \leq r, (h_{i}, h_{j}), 1 \leq i \lt j \leq r.
            \]
            

                これらは独立な生成元である。上述の議論により、これらの間の任意の関係式
            

            \[
                \prod (h_{i}^{p})^{\alpha_{i}} \prod (h_{i}, h_{j})^{\beta_{ij}} = 1
            \]
            

                は、任意の中心基本アーベル群 $\Phi(G)$ を持つ $p$-群 $G$ の生成元 $g_{1}, g_{2}, \ldots, g_{r}$ に対して、対応する関係式を意味する。$g_{i}$ で、位数を $p^{2}$ および $g_{j} = 1$ ($j \neq i$) と取ると、$\alpha_{i} = 0$ となる。また、$g_{i}$ と $g_{j}$ によって位数 $p^{3}$ の非可換群を生成し、$g_{k} = 1$ ($k \neq i, j$) とすると $\beta_{ij} = 0$ となる。したがって、$\Phi(H)$ は位数 $p^{R}$ の基本アーベル群であり、$R = \frac{1}{2} r (r + 1)$ である。また、$G \simeq H/N$ が $\Phi$-組成 $(r, s)$ を持つならば、$N$ の位数は $p^{R-s}$ である。したがって、$s \leq R$ であり、これが定理の最初の主張である。
            

            

                 さらに、もし $s \leq R$ ならば、非同型群 $G$ の数は、位数 $p^{R}$ の基本アーベル群 $\Phi(H)$ の中で、次数 $p^{R-s}$ の異なる部分群 $N$ の数より多くはない。双対性により、これは位数 $p^{s}$ のものの数と同じであり、
            

            \[
                \frac{(p^{R}-1)(p^{R}-p)...(p^{R}-p^{s-1})}{(p^{s}—1)(p^{s}—p)...(p^{s}—p^{s-1})}
            \]
            

                これは $p^{Rs-s(s-1)}$ 未満であるため、定理の右側の不等式が得られる。
            

            

                 左側の不等式を得るためには、$\Phi(H)$ のどの部分群 $N_{1}$、$N_{2}$ の組で、商群 $H/N_{1}$ と $H/N_{2}$ が同型である場合を考えればよい。$H/N_{1}$ から $H/N_{2}$ への同型写像が存在し、その写像が $h_{i}N_{1}$ を $k_{i}N_{2}$ に写すと仮定します（$i = 1, \dots, r$）。このとき、$H$ は比較的自由な群（完全不変部分群による自由群の商群）であるため、$h_{i}$ を $k_{i}$ ($i = 1$, ..., $r$) に写す $H$ の準同型写像 $\alpha$ が存在する。$k_{1}, \dots, k_{r}$ は $N_{2}$ を法として、さらに $\Phi(H)$ を法としても $H$ を生成するため、$H$ を生成します。したがって、$\alpha$ は自己同型です。また、写像 $h_{i}N_{1} \to k_{i}N_{2}$ は $H/N_{1}$ と $H/N_{2}$ 間の同型写像に拡張可能であるため、$N_{2} = \alpha(N_{1})$ である。逆に、$H$ の任意の自己同型写像 $\alpha$ に対して、$H/\alpha(N_{1})$ は当然ながら $H/N_{1}$ と同型である。したがって、$\Phi$-組成 $(r, s)$ を持つ $p$-群の同型類は、$H$ の自己同型群の下での $\Phi(H)$ の位数 $p^{R-s}$ の部分群の同値類と一対一に対応する。もし $\alpha$ が $H/\Phi(H)$ 上で恒等写像を誘導する $H$ の自己同型写像であり、$\alpha(h_{i}) = h_{i}x_{i}$ （ただし $x_{i} \in \Phi(H)$）となるならば、したがって位数 $p$ の中心元であるため、$\alpha$ は $\Phi(H)$ 上でも恒等写像を誘導する。したがって、そのような同値類に属する群の数は、高々 $H/\Phi(H)$ の自己同型群の位数以下であり、その位数は
            

            \[
                (p^{r}-1)(p^{r}-p)...(p^{r}-p^{r-1}).
            \]
            

                である。したがって、同値類の数は少なくとも
            

            \[
                \frac{(p^{R} - 1)(p^{R} - p)...(p^{R} - p^{s-1})}{(p^{s}-1)(p^{s}-p)...(p^{s}-p^{s-1})(p^{r}-1)(p^{r}-p)...(p^{r}-p^{r-1})},
            \]
            

                であり、これは $p^{Rs - r^{2} - s^{2}}$ より大きい。
            

            

                 この結果により定理 2.1 の証明が完了するが、$p > 2$ の場合にはもう少し議論を進めるとより便利になる。この場合、$H$ は類が 2 の群であり、交換子群がべき指数 $p$ であるため、通常の計算から次のことがわかる：
            

            \[
                (h_{1}^{\alpha_{1}} h_{2}^{\alpha_{2}} ... h_{r}^{\alpha_{i}})^{p} = (h_{1}^{p})^{\alpha_{1}} (h_{2}^{p})^{\alpha_{2}} ... (h_{r}^{p})^{\alpha_{r}}.
            \]
            

                 したがって、$\Phi(H)$ は $p$ 乗の元からなる群 $P$ と交換子群 $D$ の直積である。当然ながら $P$ と $D$ は共に $H$ の自己同型群を持ち、その作用の下で $P$ は $H/\Phi(H)$ と同型の演算子である。したがって、加法表記では$p$ 個の元を有する体 $F_{p}$ 上 $r$ 次元ベクトル空間 $V$ として表され、完全(full)線型群 $GL_{r}(p)$ の下で変換される。そして、このような加法的な変換において、$D$ は $V$ の外積（$V$ 自身との反対称化されたテンソル積）になる。これにより、次の定理が得られる。
            

            

                 定理 2.2. $V$ を $F_{p}$ 上 $r$ 次元ベクトル空間、$V \land V$ をその外積とします。$p \gt 2$ のとき、$\Phi$-組成 $(r, s)$ の $p$ 群の同型類の数 $g(r, s; p)$ は、$V$ 中の完全(full)線形群によって作用を受ける空間の群の下で、直和 $V \oplus V \land V$ における余次元 $s$ の部分空間の同値類の数に等しい。
            

            

                 定理 2.1 から $f_{2}(n, p)$ の上限を導くのは容易だろう。
            

            

                 定理 2.3. $\Phi$-類が 2 かつ位数 $p^{n}$ の $p$ 群の同型類の数 $f_{2}(n, p)$ は、以下を満たす：
            

            \[
                p^{\frac{2}{27} (n^{3} - 6n^{2})} \leq f_{2}(n,p) \leq (n-1) p^{\frac{2}{27} n^{3} + \frac{11}{24} n}
            \]
            

                ここで $n \geq 2$。
            

            

                 $n \geq 2$ の場合、例えばべき指数が $p^{2}$ のアーベル群など、位数 $p^{n}$ かつ $\Phi$-類が 2 の群が確実に存在します。したがって、最初の不等式は $n > 6$ のときにのみ意味を持つ。明らかに、任意の $r$、$s$ について $r + s = n$ であれば $f_{2}(n, p) \geq g(r, s; p)$ となる。$r = (2n - \delta)/3$, $s = (n + \delta)/3$ （ここで、$\delta$ は $0$, $1$, $2$ のいずれか）と置き、$r$ と $s$ を整数にすると、定理 2.1 から $f_{2}(n, p) \geq p^{N}$ が得られる。ここで、
            

            \begin{align*}
                N &= \frac{2}{27} (n^{3} - 6n^{2})                                      & \text{if} \; \delta = 0,\\
                N &= \frac{2}{27} (n^{3} - 6n^{2}) + \frac{2}{9} (n-\frac{7}{6})        & \text{if} \; \delta = 1,\\
                N &= \frac{2}{27} (n^{3} - 6n^{2}) + \frac{1}{3} (n-\frac{26}{9}) \quad & \text{if} \; \delta = 2.
            \end{align*}
            

                とする。$n > 6$ を仮定しているため、この結果が成り立つ。
            

            

                 2 番目の不等式については、
            

            \[
                f_{2}(n,p) = \sum_{r=1}^{n-1} g(r,n-r;p) \leq (n - 1)p^{M}
            \]
            

                であり、ここで $M$ は、範囲 $0 \lt r \lt n$ の中で $\frac{1}{2} r s (r + 1) - s (s - 1) \; ($s = n - r$)$ の最大値である。簡単な計算により、$r = \frac{2}{3} n + \delta$, $0 \lt \delta \lt \frac{1}{2}$ のとき最大値に達し、$M \leq \frac{2}{27} n^{3} + \frac{11}{24} n$ であることが分かる。
            


            
3. 上限

            

                 位数 $p^{n}$ の群 $G$ は、以下の形の主系列を持つ。
            

            \[
                G = G_{0} \gt G_{1} \gt G_{2} \gt \dots \gt G_{n} = 1,
            \]
            

                ここで、$G_{i}$ は $G$ において正規であり、指数 $p^{i}$ である。$i = 1, ..., n$ に対し、$G_{i-1}$ の元 $g_{i}$ は $G_{i}$ に属さないものとする。このとき、$G$ の各元は次の形で一意に表される。
            

            \[
                g_{1}^{\alpha_{1}} g_{2}^{\alpha_{2}} ... g_{n}^{\alpha_{n}} \quad (0 \leq \alpha_{i} \leq p - 1),
            \]
            

                そして $j \leq i$ に対して $\alpha_{j} = 0$ であれば $G_{i}$ に属する。さらに $g_{i}^{p}$ は $G_{i}$ に属するため、次が成り立つ。
            

            \[
                g_{i}^{p} = g_{i+1}^{\beta_{ii+1}} \dots g_{n}^{\beta_{in}}
            \]
            

                また、交換子 $(g_{j}, g_{i})$, $i \lt j$ が、$G_{j}$ に属するため、
            

            \[
                (g_{j}, g_{i}) = g_{j+1}^{\gamma_{ijj+1}} \dots g_{n}^{\gamma_{ijn}}.
            \]
            

                が成立します。このことから、$G$ の乗法表は $\beta_{ij} (i \lt j)$ および $\gamma_{ijk}, (i \lt j \lt k)$ の値の選び方によって決まるため、$f(n, p)$ の上限はこれらの選び方の数以上にはならないことが分かります。すなわち：
            

            

                 定理 3.1.
            

            \[
                f(n, p) \leq p^{\frac{1}{6} (n^{3} - n)}.
            \]
            

                 このように簡単に得られた上限が、定理 2.3 によって近似的に正しいことが示されることは、私にとって驚くべきことのように思える。
            

            

                 本節の残りでは、定理 3.1 の大きな $n$ に対する僅かな改善を行います。上記の主系列の存在は依然議論の中心だが、アプローチは少し異なる。
            

            

                 定理 3.2. $S$ を完全(full)線型群 $GL_{n}(F_{q})$ ($F_{q}$ は $q$ 個の元を持ち、$q$ は $p$ のべき) の Sylow $p$-部分群とする。$S$ の共役類の数を $q^{Bn^{2}}$ とすると、このとき、
            

            \[
                \frac{1}{12} - \epsilon_{n} \leq B \leq \frac{1}{4} + \epsilon_{n}.
            \]
            

                 $S$ を、主対角線上に 1、上三角部分に 0 を持つ $F_{q}$ 上の元を持つ $n$×$n$ 行列の群と考えます。$i$ 番目の行のある定数倍を $j$ 番目の行から引き、同じ定数倍を $j$ 番目の列に加える操作を行うと、$i \lt j$ の場合、$S$ の任意の要素を共役変換によって別の要素に置き換えることができる。明らかに、このような操作によって $S$ の任意の要素は、最初の列 (例えば $a_{1}$ 行目) の主対角線以下に多くとも一つの非ゼロ要素を持つ形に変換できる。その後、この最初の列を乱さずに（その行列を変換して）、次の列（2 列目）でも同様の操作を行い、主対角線以下に非ゼロ要素が存在するのは多くとも $a_{1}$ 行目とさらに一つの行（例えば $a_{2}$ 行目）のみとなるようにする。この操作を $[n/2]$ 列目まで繰り返すと、$n$ が偶数の場合であれば、主対角線以下の非ゼロ要素がある場所の最大数は $n^{2}/4$ であり、$n$ が奇数の場合であれば $(n^{2} - 1)/4$ であることが分かる。これらの場所は、$n - 1$ 未満の異なる整数から成る列 $a_{1}$, $a_{2}$, … によって決定される。すなわち、（共役？）類の数は $(n - 1)! q^{\frac{1}{4} n^{2}}$ 未満である。しかし、$q \geq 2$ に対して$(n - 1)!$ は $q^{\epsilon_{n} n^{2}}$ であるから、上限の不等式が従う。
            

            

                 下限の不等式を得るために、$J$ を副対角線上†に非ゼロ要素を持ち、その他の場所はゼロである正方行列とする。$X$ を右下隅から始まる対角線上に非ゼロ要素を持ち、対角線の下がゼロである行数が列数以上の行列とする。$Y$ を左上隅から始まる対角線上に非ゼロ要素を持ち、対角線の下がゼロである 列数が行数以上の行列とする。このような形の行列
            

            \begin{bmatrix}
            I &   &   &  \\
            X & I &   &  \\
              & J & I &  \\
              &   & Y & I
            \end{bmatrix}
            

                が $S$ において共役であるためには、それらが同値でなければならないことが簡単に確認できる。下限は、$X$ の行数を列数の2倍とし、$Y$ についても逆もまた同様にして、自由に選べる要素の数を数えることで得られます。
            

            

                 定理 3.2 のギャップを埋めることができれば興味深いだろう。また、$n$ の値が小さい場合に考察することで示唆されるように、固定された $n$ に対して、類の数が $q$ の多項式であるかどうかを知ることも興味深い。
            

            

                 定理 3.3. $H$ が $GL_{n}(F_{q})$ の任意の部分群である場合、$H$ の $p$-元†の共役類の数は $q^{(\frac{3}{8} + \epsilon_{n})n^{2}}$ 未満になる。
            

            

                 $H$ が $p$-群であると仮定でき、さらに $S$ に含まれると考えても一般性を失わない。$H$ が共役作用によって置換群として自身にはたらくことを認めるならば、その共役類は推移的な系（群作用）になる。これらの系の数に関する通常の公式（バーンサイド (1), 191）は、
            

            \[
                o(H)c(H) = \sum_{h \in H} o(C(h))
            \]
            

                によって与えられる。ここで $o(H)$ は $H$ の位数、$c(H)$ は共役類の数、$C(h)$ は $H$ における $h$ の中心化群。これを $S$ に対する対応する式と比較すると、
            

            \[
                o(H)c(H) \leq o(S)c(S)
            \]
            

                が得られる。したがって $c(H) \leq (o(S)c(S))^{\frac{1}{2}}$。$o(S) = q^{\frac{1}{2}n(n-1)}$ と定理 3.2 の $c(S)$ の上限を代入することで結果が得られる。
            

            

                 定理 3.4. $G$ が位数 $p^{n}$ の群であるとき、$G$ を指数 $p$ の正規部分群として含む群の同型類の数は、$p^{(\frac{2}{5} + \epsilon_{n})n^{2}}$ 未満である。
            

            

                 $G_{1} \supset G$ を $G$ と元 $t$ から生成される群とし、$t^{p} = g$ が $G$ の要素であり、$\tau: x \to t^{-1}xt$ は $G$ の自己同型写像とする。$g$ と $\tau$（これらは任意ではない）は $G_{1}$ の同型類を決定する。さらに $\tau$ を共役自己同型写像 $\sigma^{-1} \tau \sigma$ に置き換え、同時に $g$ を $g^{\sigma}$ に置き換えても、$G_{1}$ の同型類は変化しない。したがって、同型類の数は、高々 $G$ の自己同型群 $A$ における $p$-元の類の数に $p^{n}$ を掛けたものであり、この因数 $p^{n}$ は現在の文脈では無視できる。今、$G$ が $r$ 個の生成元で生成されるとすると、$A$ には $G/\Phi(G)$ 上で恒等写像を誘導するあれらの自己同型写像から成る $p^{r(n - r)}$ で割り切れる位数の正規部分群 $N$ が含まれる (Hall (2))。商群 $A/N$ は、位数 $p^{r}$ の基本アーベル群 $G/\Phi(G)$ の自己同型群、つまり $GL_{r}(F_{p})$ の部分群に同型である。$A$ における $p$-元の類の数は、高々 $A/N$ におけるものの $p^{r(n - r)}$ 倍以下であり、定理 3.3 により $p^{C}$ 以下。ここで、
            

            \begin{align*}
                C &= (\frac{3}{8} + \epsilon_{r})r^{2} + r(n - r)\\
                  &= \frac{2}{5} n^{2} - \frac{2}{5} (n - \frac{5}{4}r)^{2} + \epsilon_{r} r^{2}\\
                  &\leq \frac{2}{5} n^{2} + \epsilon_{r} r^{2}.
            \end{align*}
            

                $r \leq n$ であるため、これは $\frac{2}{5} n^{2} + \eta_{n} n^{2}$ となり、$n$ が無限大に近づくとき $\eta_{n}$ はゼロに収束する。よって示された。
            

            

                 これで $f(n, p)$ の上限を得る準備が整った。同時に、定理 2.3 から下限も求める。
            

            

                 定理 3.5. 位数 $p^{n}$ の群の同型類の数 $f(n,p)$ は、$f(n,p) = p^{An^{3}}$ を満す：
            

            \[
                \frac{2}{27} - \epsilon_{n} \leq A \leq \frac{2}{15} + \epsilon_{n}.
            \]
            

                 ここで、定理 2.3 の前半から、上の不等式の前半が得られます。後半については、位数 $p^{n}$ の任意の群には位数 $p^{n - 1}$ の正規部分群が存在するため、定理 3.4 から次が導かれます：
            

            \[
                f(n,p) \leq p^{(\frac{2}{5} + \epsilon_{n})(n - 1)^{2}}f(n - 1,p),
            \]
            

                したがって、
            

            \[
                A n^{3} \leq \sum_{r=1}^{n-1} (\frac{2}{5} + \epsilon_{r}) r^{2} = (\frac{2}{15} + \epsilon_{n}) n^{3}.
            \]
            

                 定理 3.2 の上限を改善できれば、定理 3.3 から定理 3.5 までの上限も改善されることが明らかです。しかし、$GL_{n}(F_{q})$ が偶数の場合には位数 $q^{\frac{1}{4} n^{2}}$ のアーベル部分群を含み、$n$ が奇数の場合には位数 $q^{\frac{1}{4} (n^{2} - 1)}$ のアーベル部分群を含むため、定理 3.4 の $\frac{3}{8} + \epsilon_{n}$ は $\frac{1}{4}$ より小さくすることはできません。これは、定理 3.5 における上限を $\frac{1}{9} + \epsilon_{n}$ にするに留まるため、上下のギャップを埋めることはできません。
            

            It is clear that any improvement in the upper bound in Theorem 3.2 would lead to an improvement in the upper bounds in Theorems 3.3 to 3.5. However, $GL_{n}(F_{q})$ contains abelian subgroups of order $q^{\frac{1}{4} n^{2}}$ if $n$ is even and $q^{\frac{1}{4} (n^{2} - 1)}$ if $n$ is odd, so that the $\frac{3}{8} + \epsilon_{n}$ in Theorem 3.4 cannot be improved beyond $\frac{1}{4}$. This would give an upper bound of $\frac{1}{9} + \epsilon_{n}$ in Theorem 3.5, and so would not close the gap between the two sides.
