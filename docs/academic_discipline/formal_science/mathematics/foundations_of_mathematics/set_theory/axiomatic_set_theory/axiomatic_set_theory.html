公理的集合論

目次[表示]

  • 概要

概要

 素朴集合論では、「ある性質を満たすもの全体の集合」といった直観的な理解に基づき集合を定義していた。しかし、この自由な集合の構成方法は、様々な矛盾を引き起こす可能性がある。こうした問題を回避するために、集合の存在と構成を明確な「公理系」に基づいて定める「公理的集合論」が生まれた。
